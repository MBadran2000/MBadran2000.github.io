# Mohamed Badran — Academic Website

A professional, minimal, mobile-friendly academic website intended for prospective PhD supervisors. It is a static HTML/CSS site, with no frameworks, trackers, or build step.

## Quick start

Open `index.html` in a browser. The site works offline, except links to external publications and profiles.

## Publish for free using GitHub Pages

1. On GitHub, create a **public** repository named `MBadran2000.github.io` (if using your `MBadran2000` account).
2. Upload the **contents of this folder** directly to the repository root. Do not upload only the ZIP file or place the files in a nested directory.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, set the branch to `main` and folder to `/ (root)`, and save.
4. Once the site has been deployed, it will be available at `https://mbadran2000.github.io/` (subject to GitHub account/repository setup).

Alternatively, upload these files to any static web host (Netlify, Cloudflare Pages, etc.).

## Edit the website

- `index.html` — all page content, including profile, papers, projects, experience and links.
- `styles.css` — layout, typography and colors. Change `--accent` and `--accent-dark` near the top to change the accent color.
- `Mohamed_Badran_CV.pdf` — replace this file with your latest CV while keeping the filename unchanged, so the Download CV link remains valid.
- `favicon.svg` — small tab icon.

## Before publishing

- Review every project summary and publication entry for accuracy.
- Update the CV whenever you revise it.
- A **publication author-list discrepancy** was identified: the supplied CV lists Marwan Torki as a coauthor of the SemEval 2025 paper, while its published ACL Anthology entry lists Nagwa El-Makky. This website uses the **published ACL Anthology** author list. Consider fixing the CV if appropriate.
- The public website intentionally **does not display a phone number**. Contact is through your university email, and the CV PDF retains the contact details from the supplied original.
- If you use a GitHub account other than `MBadran2000`, update the GitHub URLs in `index.html`.

## Notes

Paper links lead to official ICLR proceedings, MICCAI, ACL Anthology, or IEEE DOI pages. The site's author names follow the published proceedings where available.
